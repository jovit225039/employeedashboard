# Employee Dashboard - Assignment 2

A React-based Employee Dashboard created according to the assignment requirements.

## Features

- React library used for the application.
- Navbar with Home and Employee Form links.
- Home/Dashboard page fetches employee data from:
  https://jsonplaceholder.typicode.com/users
- Displays API data in a table with:
  - ID
  - Name
  - Email
- Employee Form contains:
  - Name
  - Designation
  - Location
  - Salary
- React Router is used for navigation.
- Bootstrap is used as the CSS library.
- No backend/post API is required.

## Requirements

Install Node.js before running the project.

## Run in VS Code

Open this folder in VS Code, then open the terminal and run:

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, normally:

http://localhost:5173/

## Build

```bash
npm run build
```
